# Reaction Time Test / Тест на реакцию

**[👉 Открыть тест реакции в браузере (Open Reaction Test)](https://mookoom39.github.io/reaction-test/)** 

Простой локальный тест времени реакции, работающий прямо в браузере без сетевого пинга (с опциональным звуковым сигналом и историей последних 20 кликов).
A simple local reaction time test running directly in the browser with zero network ping (featuring an optional audio cue and a history of the last 20 clicks).
